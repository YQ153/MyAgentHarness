# 全局长期记忆

跨会话仍然有效的用户偏好与项目约定。**本文件是全局记忆**：不管会话绑定哪个工作空间，
Agent 每次运行都会加载它——应用把它以只读方式挂载在 `/global/AGENTS.md`。它不属于任何
单条会话或某个工作区；要改它就改这个文件，Agent 改不动它。

## 用户偏好

- 用户称呼：言先生。
- 回复语言：简体中文。

## 项目约定

- 涉及具体文件时以**该会话的工作区**为准；本文件所在目录不是任何会话的工作区，放在
  这里的资料默认读不到，需要时先复制进工作区。
- 工具返回的大结果先落盘再引用，不要把长文本直接粘贴到对话里。
- 修改已有文件优先用 `edit_file`，避免整文件覆盖。

## 环境限制

- 有联网工具（web_search / web_fetch），但只支持公网 http/https；内网、本机、链路本地
  地址会被拒绝。
- 工作区内的资料优先于联网结果；用户要求「基于知识库」时只看工作区文件。
- 查国内城市天气优先用 `nmc.cn/publish/forecast/ASC/[城市拼音].html`（中央气象台）；
  `weather.cma.cn` 有 WAF 人机验证，抓不到正文。
- 有 `execute`（shell）工具。偶发 `fork: Resource temporarily unavailable`（exit 254）时
  不要反复重试同一写法，换个写法或直接 `write_file` 落盘。
