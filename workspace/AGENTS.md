# 长期记忆

这里记录跨会话仍然有效的用户偏好与项目约定。Agent 会在每次启动时加载本文件。

## 用户偏好

- 用户称呼：言先生。
- 回复语言：简体中文。

## 项目约定

- 工作区即本文件所在目录，所有相对路径以此为准。
- 工具返回的大结果应先落盘再引用，不要把长文本直接粘贴到对话里。
- 修改已有文件优先用 `edit_file`，避免整文件覆盖。

## 环境限制

- 本沙箱**没有联网工具**（无 web search / fetch），无法获取实时数据；
  涉及“最新排行、实时行情、新闻”类需求时，须先说明无法联网核实，
  再给出基于既有知识的参考信息并标注时效，不要伪造精确数据。
- 本沙箱**没有 shell / 终端工具**，无法执行 `npm`、`git` 等命令。
  涉及项目脚手架、安装依赖之类需求时，只能按官方模板手工用 `write_file`
  落盘各文件，并在交付说明中告知用户自行运行 `npm install` / `npm run dev`。
