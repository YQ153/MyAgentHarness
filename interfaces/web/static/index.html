我的记忆

Agent 写进 /memories/ 的内容会跨会话保留，并进入后续每一轮 上下文。记错的内容在这里删掉——删除会记入审计日志。

选择工作区

任意目录都可以选。选中的目录会成为这条会话的文件根——此后不再改变，换项目请新建会话。 也可以直接粘贴路径，或什么都不选（那条会话将使用应用为它创建的专属目录）。

工作区

Agent 的文件读写、命令产物都落在这个目录里。面板只读——要改动请通过对话让 Agent 做， 这样才会经过人工审批。

知识库

索引工作区里的文本文档后，Agent 可通过 search_documents 检索到它们。 索引只读工作区文件；「移除」只清掉索引，不会删除源文件。

技能

技能是 Agent 会加载的指令包，放在工作区的 skills/ 目录里。 启停只对之后新建的会话生效——已在进行的会话沿用它们启动时加载的那一份。 技能包本身的新增与修改请直接改文件系统：那条路径同样受人工审批约束。
